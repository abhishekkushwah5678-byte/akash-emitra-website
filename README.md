## स्थानीय रूप से चलाएँ
1. ZIP को Extract करें।
2. `index.html` पर डबल-क्लिक करें। `logo.jpg` उसी फ़ोल्डर में होना चाहिए।

## मुफ़्त GitHub Pages होस्टिंग
1. GitHub पर नया Public repository बनाएँ, उदाहरण `akash-emitra-website`.
2. `index.html` और `logo.jpg` दोनों अपलोड करें (या ZIP extract करके दोनों फाइलें डालें)।
3. Settings → Pages → Deploy from a branch चुनें।
4. Branch `main`, folder `/(root)` चुनें और Save करें।
5. Pages सेक्शन में प्रकाशित लिंक मिलने पर उसे खोलें।
